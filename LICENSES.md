# LICENSES

**Rule (GDD 24):** if you cannot name the licence for an asset, do not ship it.
Every row below must be filled in before the week-11 audit. This file is also what
backs the **"No generative AI was used"** store tag — keep it detailed enough to
defend the claim.

Legend for *Source*: `own` = made by you, `cc0` = public domain, `ccby` = attribution
required, `ccbync` = non-commercial (do **not** ship these if you ever charge),
`lib` = free library (name it), `gen` = procedurally generated by a script in `tools/`.
